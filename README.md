# 🚀 AI Backend Project

A Node.js backend project built with Express, MongoDB, validation, and Swagger documentation.

---

## 📌 Features

- ✅ REST APIs (CRUD operations)
- ✅ MongoDB integration (Mongoose)
- ✅ Validation using Zod
- ✅ Global error handling
- ✅ Logging middleware
- ✅ Swagger API docs (/docs)
- ✅ Clean architecture (controller/service pattern)

---

## ⚙️ Tech Stack

- Node.js
- Express.js
- MongoDB (Mongoose)
- Zod (validation)
- Swagger (API documentation)
- ESLint + Prettier
